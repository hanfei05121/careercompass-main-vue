# 2026-09-09

## 新增卡片滑动动效展示模块（/cards）

按用户给的 10 种卡片滑动动画描述，新建 `src/views/app/cards/`：

- **路由**：利用项目的文件路由约定自动生成 —— `views/app/cards/index.vue` → `/cards`，`views/app/cards/[type].vue` → `/cards/:type`；`components/` 目录按约定自动排除，不会变成路由。
- **动画组件**（`components/animations/`）：StackSwipe 层叠滑走、Coverflow 封面流、SnapCarousel 横向吸附、FanSpread 扇形展开、FlipSwipe 掀牌翻转、WheelScroll 纵向滚轮、CubeRotate 立方体面、PeekSide 侧边窥视、ExplodeGather 打散聚拢、OvershootSlide 过冲滑入。
- **共享能力**：`DeckCardFace.vue`（统一卡片外观）、`composables/usePointerDrag.ts`（pointer 事件统一处理拖拽 + 速度计算）、`types.ts`（8 张演示卡 + 10 种动画清单元数据）。
- **交互**：每个组件 expose `next/prev`；详情页提供上一张/下一张、自动播放、动效间切换，键盘 ← → 切卡、空格自动播放；拖拽跟手，松手按位移/速度判定切换或回弹，首尾循环。
- **接入**：`router/meta.ts` 的 pageTitleMap、AppSidebar（Layers 图标）、zh-CN/en-US 的 menu.ts 均加上「卡片动效 / Card Motion」。

踩坑记录：
- `:style` 绑定里 `visibility` 三元表达式会被推断成 `string`，vue-tsc 报 TS2345，需写成 `as 'hidden' | 'visible'`。
- 卡片用 `translate` 做变换时不能被 tailwind 的 `-translate-x-1/2` 居中，改用 `-ml-[120px] -mt-[160px]` 固定尺寸居中。
- CSS animation 优先级高于 inline style：拖拽跟手的 transform 与入场动画要分层（外层 inline transform，内层 animation）。
- 本机 curl 探测 localhost 需加 `--noproxy '*'`（环境设了 http_proxy）；9002 端口常被占用，vite 会顺延到 9003。
