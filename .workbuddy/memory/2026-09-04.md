## 关闭登录鉴权（Firebase Auth）

需求：登录页报 `Login Failed / Firebase is not initialized`，用户要求把鉴权整套关掉。

排查结论：项目只有 `.env.example` 没有 `.env`，Vite 不读取 `.env.example`，导致
`VITE_FIREBASE_*` 全为 undefined → `isConfigValid` 为 false → `app/auth/db` 保持 null →
`login()` 抛错。

改动（新增总开关，默认关闭鉴权，保留 Firestore 数据层）：

- 新增 `src/lib/authConfig.ts`：`AUTH_ENABLED = import.meta.env.VITE_AUTH_ENABLED === 'true'`
- `src/env.d.ts`：补充 `VITE_AUTH_ENABLED?: string` 类型
- `src/stores/auth.ts`：关闭时注入 GUEST_USER / GUEST_PROFILE（role=employee），
  `loading` 初始为 false，`isAuthenticated` 恒为 true，`initAuth` 空转，
  login/signup/logout 短路不再触碰 Firebase
- `src/router/index.ts`：`beforeEach` 开头 `if (!AUTH_ENABLED)` 全放行，
  并把根路径 `/` 直接导向 `dashboard`
- `src/views/Home.vue`：关闭时直接 push `/dashboard`
- `.env.example`：补充 `VITE_AUTH_ENABLED=false` 说明

验证：`npx vite build` 通过；dev server 起在 9002，`/dashboard` 返回 200，
`AUTH_ENABLED` 编译为 false，服务端无报错。

## 注意：项目原有 9 个 vue-tsc 报错（非本次引入）

`npm run typecheck` 在改动前就有这些错误，属历史遗留：
AppSidebar 未用变量 `dashboardHref`、router 未用参数 `from`、
auth.ts 未用变量 `firestore` 且 `doc(db, ...)` 传了 `Firestore | null`、
Login.vue `userDocSnap.data()` 可能 undefined、Signup.vue 类型比较、
Dashboard.vue 未用 `authStore`、Opportunities.vue `db` 可能为 null。

因为 `npm run build` 会先跑 `vue-tsc`，这些错误会让 build 失败；
单独跑 `npx vite build` 可以正常构建。若之后要启用 `npm run build`，需先修掉这批。
